<arguments>$ARGUMENTS</arguments>

Prompt Engineer 에이전트(`.claude/agents/prompt-engineer.md`)로 위 프롬프트를 처리한다. 작업 전에 "Prompt Engineer를 사용합니다"라고 한 줄로 알린다.

1. **입력 준비**
   - URL이면 내용을 가져온다. 가져올 수 없으면 사용자에게 붙여넣어 달라고 한다.
   - 키워드만 주고 "찾아 줘"라고 하면 연결된 프롬프트 라이브러리 검색(search_prompts)을 써도 된다. 검색 정확도가 낮으므로 후보 3개 이내를 보여 주고 사용자가 고르게 한다.
   - 인자가 비어 있으면 프롬프트를 붙여넣어 달라고 요청하고 멈춘다.
2. **정보 확인**: 용도, 결과물, 사용할 AI 도구를 `prompts/my-context.md`와 `.agents/product-marketing.md`로 알 수 없으면 질문 3개 이내로 먼저 묻는다. 서브에이전트는 중간에 사용자에게 물을 수 없으므로, 질문은 이 단계에서 끝낸다.
3. **위임**: 원본 프롬프트, 출처, 사용자 답변, "저장" 여부를 모두 담아 Prompt Engineer 에이전트에게 맡긴다.
4. **전달**: 에이전트가 쓴 결과를 요약하거나 줄이지 말고 그대로 보여 준다. 변경 이유와 학습 설명도 결과물의 일부다.
5. 사용자가 이전 회차의 연습 과제를 제출하면, 같은 에이전트에게 피드백을 맡긴다.

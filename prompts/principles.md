# 프롬프트 작성 원칙 (P01~P14)

Prompt Engineer가 변경 이유를 설명할 때 근거로 쓰는 목록입니다. 공부할 때는 이 문서를 처음부터 한 번 읽고, 이후에는 결과 설명에 나온 원칙 ID를 찾아보세요.

주요 근거: Anthropic, OpenAI 등 모델 제공사의 공식 프롬프트 작성 가이드. 효과의 크기는 모델과 작업에 따라 다르므로, 중요한 프롬프트는 원본과 수정본을 같은 입력으로 돌려 직접 비교하는 것이 가장 확실한 검증입니다.

## 진단 점검표

| 항목 | 질문 | 관련 원칙 |
|---|---|---|
| 목적 | 무엇을, 왜 만드는지 분명한가? | P02, P03 |
| 독자 | 결과물을 누가 읽고 보는가? | P04 |
| 맥락 | 모델이 모르는 배경(브랜드, 상황)을 주었는가? | P03 |
| 입력 구분 | 지시와 참고 자료가 섞여 있지 않은가? | P05 |
| 출력 형식 | 길이, 구조, 형식이 정해졌는가? | P06 |
| 지시 방식 | "하지 마"보다 "이렇게 해"로 썼는가? | P07 |
| 예시 | 원하는 결과의 예가 있는가? (필요할 때) | P08 |
| 복잡도 | 여러 작업을 한 번에 시키지 않는가? | P09, P13 |
| 제약 | 법규, 브랜드, 금지 표현이 들어갔는가? | P10 |
| 재사용 | 바뀌는 값이 변수로 빠져 있는가? | P11 |
| 검증 | 결과를 스스로 점검할 기준이 있는가? | P12, P14 |

## 원칙

### P01. 역할은 맥락과 함께 준다
"너는 마케터야" 한 줄만으로는 효과가 제한적입니다. "B2B SaaS를 10년 해 온 퍼포먼스 마케터로서, 전환율 관점에서 검토해 줘"처럼 **관점과 기준**까지 줄 때 결과가 달라집니다.

### P02. 목적과 성공 기준을 밝힌다
"홍보 문구 써 줘" → "신제품 사전 예약 신청을 늘리는 인스타그램 문구. 성공 기준: 첫 문장에서 혜택이 보일 것".

### P03. 이유와 배경을 설명한다
규칙만 주기보다 **왜 그런지** 알려 주면 모델이 규칙에 없는 상황에도 맞게 판단합니다. 예: "짧게 써" → "모바일에서 스크롤하다 보는 문구라 짧아야 해".

### P04. 독자를 구체적으로 정한다
"고객" 대신 "아이 둘을 키우며 퇴근 후 30분 안에 저녁을 해결하려는 30대 직장인"처럼 정합니다. 독자가 구체적일수록 단어와 톤이 정확해집니다.

### P05. 지시와 자료를 구분한다
참고 자료, 원문, 데이터는 `<자료>...</자료>` 같은 태그나 구분선으로 감쌉니다. 모델이 자료 속 문장을 지시로 오해하지 않습니다.

### P06. 출력 형식을 지정한다
분량, 구조(제목, 본문, CTA), 표/목록 여부, 버전 개수(예: "3안")를 정합니다. 원하는 형식을 직접 보여 주면 가장 정확합니다.

### P07. 금지보다 원하는 방향을 쓴다
"딱딱하게 쓰지 마" → "친구에게 추천하듯 대화체로 써". 금지만 있으면 무엇을 해야 하는지가 비어 있습니다.

### P08. 예시는 다양하게, 베끼지 않게
예시 1개는 그대로 복제될 위험이 있습니다. 성격이 다른 예시 2~3개를 주고 "형식만 참고하고 내용은 새로 써"라고 덧붙입니다.

### P09. 복잡한 작업은 단계로 나눈다
"분석 → 메시지 도출 → 문구 작성"처럼 순서를 주거나, 먼저 생각을 정리하게 한 뒤 결과를 쓰게 합니다.

### P10. 제약 조건을 명시한다
브랜드 금지어, 법적 제약(근거 없는 "최고/최초/1위" 같은 표현은 「표시·광고의 공정화에 관한 법률」상 문제가 될 수 있음), 채널 규격을 적습니다.

### P11. 바뀌는 값은 변수로 뺀다
`{{제품명}}`, `{{타깃}}`, `{{채널}}`처럼 만들어 두면 한 프롬프트를 여러 캠페인에 다시 쓸 수 있습니다.

### P12. 자기 점검 기준을 넣는다
"다 쓴 뒤 다음 기준으로 점검하고 고쳐서 내놔: ① 혜택이 첫 문장에 있는가 ② 금지어가 없는가".

### P13. 한 프롬프트에는 한 가지 핵심 작업
기획, 카피, 이미지 프롬프트를 한 번에 시키면 셋 다 얕아집니다. 나눠서 이어 붙입니다(체이닝).

### P14. 지어내지 못하게 막는다
"주어진 자료에 없는 수치나 사례는 만들지 말고 [확인 필요]로 표시해". 마케팅 문구에 가짜 통계가 들어가는 사고를 막습니다.

## 흔한 오해

- **"대문자, '반드시', '절대'를 많이 쓸수록 잘 따른다"**: 최신 모델은 지나친 강조에 과하게 반응해 다른 지시를 무시하기도 합니다. 중요한 규칙은 이유와 함께 한 번 분명히 쓰는 편이 낫습니다(P03).
- **"팁을 준다고 하면 결과가 좋아진다"**: 일관된 근거가 없습니다. 목적, 맥락, 형식을 분명히 하는 것이 훨씬 확실합니다.
- **"길수록 좋은 프롬프트다"**: 역할 없는 문장은 오히려 중요한 지시를 흐립니다. 문장마다 하는 일이 있어야 합니다.

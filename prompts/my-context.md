# 내 상황 프로필

Prompt Engineer가 프롬프트를 고칠 때 매번 반영하는 정보입니다. 비워 둔 항목은 에이전트가 추측하지 않고 필요할 때 물어봅니다.

## 브랜드·타깃·톤은 한곳에서 관리합니다

브랜드, 타깃, 고객 언어, 톤, 근거 자료(수치·후기)는 **`.agents/product-marketing.md`** 한 파일에 둡니다. 마케팅 스킬(copywriting, copy-editing, social)과 Prompt Engineer가 모두 이 파일을 읽습니다.

- 파일이 아직 없으면 `/product-marketing`을 실행해 질문에 답하면 만들어집니다. 한국어로 답해도 됩니다.
- 수정할 때도 `/product-marketing`을 쓰면 버전과 변경 기록이 함께 남습니다.

## 이 파일에만 적는 것 (프롬프트 작업용)

### 주 용도
- 마케팅·홍보물 제작 (주), 업무 문서 (부)

### 자주 쓰는 채널
- (예: 인스타그램, 네이버 블로그, 카카오톡 채널, 보도자료, 현수막, 리플렛)

### 사용하는 AI 도구
- 글: (예: Claude, ChatGPT)
- 이미지: (예: Adobe Firefly, Midjourney)

### 결과 프롬프트 언어
- 기본: 한국어 (이미지 생성 프롬프트는 영어를 원하면 여기에 적기)

### 학습 방식
- 결과와 함께 변경 이유, 적용 원칙, 연습 과제를 받는다.
